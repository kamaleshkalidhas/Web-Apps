# Web App

React Native WebView Application for Android Devices.

## 📱 About The Project

web App is a lightweight React Native application developed to load and display a website inside a native Android application using the `react-native-webview` package.

The application provides users with a seamless mobile experience by wrapping the website inside a native container while maintaining smooth navigation and performance.

The app also includes internet connectivity checking functionality to ensure proper user experience during network availability changes.

---

## ✨ Features

- 🌐 Website integration using `react-native-webview`
- 📶 Internet connectivity status checking
- 📱 Native Android application experience
- ⚡ Lightweight and fast performance
- 🔄 Smooth website loading inside mobile app
- 🛠️ Simple and maintainable code structure
- 📦 APK generation for Android devices

---

## 🛠️ Tech Stack

- React Native CLI
- JavaScript
- react-native-webview
- NetInfo / Internet Connectivity Package
